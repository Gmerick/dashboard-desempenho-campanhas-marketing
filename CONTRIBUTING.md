# Como contribuir

1. Crie uma branch a partir de `main`.
2. Faça mudanças pequenas e documentadas.
3. Execute `python -m unittest discover -s tests -v`.
4. Não inclua dados pessoais, credenciais ou bases confidenciais.
5. Abra um pull request explicando problema, solução e como a mudança foi validada.

Sugestões bem-vindas: novas análises SQL, medidas DAX, testes de qualidade, melhoria de acessibilidade e adaptação para bases públicas.
